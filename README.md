# 🪙 WeeklyBudget Tracker

A clean, responsive, single-page web application designed for tracking weekly and monthly expenses with a polished sage green aesthetic, multi-language support, real-time cloud synchronization, and PDF report generation.

---

## ✨ Features

- **🎨 Modern Sage Green UI**: Soft cream and sage green aesthetic (`#8A9A86`) with smooth card layouts and full **Dark/Light Mode** support.
- **🌐 Multi-Language Support**: Dynamic UI translation supporting English, Traditional Chinese (繁體中文), and Simplified Chinese (簡體中文).
- **🔒 Firebase Authentication & Cloud Sync**: Secure user login via Firebase Auth with real-time Firestore database synchronization and automatic local storage fallback.
- **💰 HKD Currency Lock**: Standardized Hong Kong Dollar (HKD) formatting across all financial summaries, input forms, and logs.
- **📅 Interactive Calendar View**: Month and weekly grid view displaying daily spending totals and quick entry management.
- **📊 Analytics & Reports**: Visual breakdown of spending categories, daily comparisons, and instant **PDF/CSV Report Generation**.

---

## 🛠️ Tech Stack

- **Frontend**: React, Tailwind CSS, Lucide React Icons
- **Database & Auth**: Firebase (Authentication & Cloud Firestore)
- **Utilities**: jsPDF (for report generation)
- **Deployment**: Vercel (Continuous Deployment via GitHub)
